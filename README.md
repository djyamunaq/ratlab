# RatLab 3D Environment

A PyGame and OpenGL-based 3D simulation environment for autonomous agent navigation and trajectory generation.

## Features

- 3D Environment: OpenGL-rendered 3D world with objects and grid system

- Autonomous Agent: Ornstein-Uhlenbeck process for realistic movement

- View Capture: Save agent's perspective as images

- Real-time Visualization: Live trajectory plotting

## Installation

```
git clone https://github.com/djyamunaq/ratlab.git
pip install -r requirements.txt
```
